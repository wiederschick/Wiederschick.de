WiederSchick Website – Upload-Hinweise

1. Vor Veröffentlichung unbedingt Impressum und Datenschutz vervollständigen.
   Gelb markierte Platzhalter enthalten noch fehlende Pflichtangaben.

2. Alle Dateien aus diesem Ordner gemeinsam auf den Webspace hochladen.
   Die Startseite heißt bereits index.html.

3. Wichtig:
   - styles.css
   - script.js
   - assets/whatsapp-qr.png
   müssen zusammen mit den HTML-Dateien hochgeladen werden.

4. Aktuell enthalten:
   - Startseite
   - Shop-Vorschau
   - Ankauf
   - Über uns
   - Kontakt
   - Impressum
   - Datenschutz
   - WhatsApp-Kanal mit QR-Code

5. Für einen echten Warenkorb/Checkout muss später ein Shopsystem angebunden werden.
